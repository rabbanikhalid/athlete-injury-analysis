# &#x20;⚽ Athlete Injury & Performance Analysis Dashboard  

## 📌 Overview

This project presents an end-to-end data analytics pipeline to analyze the impact of player injuries on performance and team outcomes across Premier League clubs (2019–2023).

The objective is to uncover insights into injury trends, recovery patterns, and performance changes using data-driven analysis and interactive visualization.

---

## 🛠️ Tech Stack

* Python (Pandas, NumPy)
* Power BI (Dashboard & Visualization)
* Google Colab

---

## 🔄 Project Workflow

* Data Collection (Kaggle dataset - Premier League injuries)
* Data Cleaning & Preprocessing (Python)
* Feature Engineering (Performance metrics, recovery days, age groups)
* Exploratory Data Analysis
* Dashboard Development (Power BI)
* Insight Generation & Reporting

## 📈 Dashboard Features

* Injury trends over time
* Injury type distribution
* Performance impact by injury type
* Recovery duration analysis
* Player performance before vs after injury
* Age group injury analysis
* Interactive filters (team, position, age group, year)

---

## 🔍 Key Insights

* ~51% of players show improved performance post-injury
* Certain injuries (e.g., fractures, ligament issues) have higher performance impact
* Average recovery time is ~30 days
* Prime-age players experience the highest number of injuries
* Frequently occurring injuries do not always have the highest performance impact

---

## 📊 Dataset

* Source: Kaggle (Premier League Injury Dataset)
* ~600 raw records, cleaned to ~350+ records for analysis
* Includes:

  * Player details (age, position, team)
  * Injury type and duration
  * Match performance before and after injury
  * Recovery timelines

---

## 🚀 Conclusion

This project demonstrates how data analytics can be applied in sports to evaluate injury impact, performance trends, and recovery patterns. The dashboard enables interactive exploration of insights, supporting data-driven decision-making in sports analytics.
